# CrimeVision AI | Digital Forensics

**CrimeVision AI** is an AI-assisted digital forensics application designed to analyze digital image evidence and generate structured technical reports.

### Key Features
- Image Evidence Upload and Analysis
- Image Metadata and EXIF Inspection
- Image Quality Assessment
- Brightness and Sharpness Measurements
- Structured Evidence Reports

### Tech Stack
- **Frontend:** React, Vite, JavaScript, CSS
- **Backend:** Python, Flask
- **Image Processing:** Python imaging libraries and configured analysis dependencies

### Getting Started
Clone the repository and follow the frontend and backend setup instructions to install dependencies and run the application locally.

### Purpose
To simplify technical image examination through an accessible interface and organized evidence reporting.

### Disclaimer
CrimeVision AI is an investigative assistance tool. Its automated results do not independently establish the authenticity of digital evidence and should be reviewed by qualified professionals.
